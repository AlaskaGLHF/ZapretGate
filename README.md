# <a href="https://github.com/AlaskaGLHF/ZapretGate">ZapretGate</a>

**ZapretGate — это удобное приложение для управления утилитой обхода блокировок `zapret-discord-youtube` от Flowseal.**

Простой графический интерфейс вместо консольных скриптов: включайте обход одним кликом, выбирайте стратегии, настраивайте игровые фильтры, обновляйте файлы и следите за процессами — всё в одном окне.

Работает поверх оригинального репозитория [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)

</div>

> [!IMPORTANT]
> **ZapretGate** — это графическая оболочка (WPF / .NET 8) над системными скриптами и бинарниками из репозиториев **Flowseal**. Само приложение ничего не блокирует — оно просто управляет утилитой через красивый интерфейс.

## ⚡ Производительность и системные требования

Приложение написано на **C# / .NET 8** с использованием нативных элементов **WPF-UI**. Работает быстро, потребляет минимум ресурсов и не мешает системе в фоне.

| Метрика | Значение | Описание |
| :--- | :--- | :--- |
| **Потребление ОЗУ** | **~25–35 МБ** | В фоновом режиме практически незаметно. |
| **Нагрузка на CPU** | **~0.2%** | Интерфейс без лишних анимаций. Основная работа ложится на `winws.exe`, который трудится на уровне сетевого стека WinDivert. |

## 📦 Системные требования и выбор сборки

Для работы приложения необходима операционная система **Windows 10 / 11 (x64)** и права администратора.

В разделе релизов доступны два варианта сборки:
1. **Обычная сборка:** Легковесный дистрибутив. Требует наличия установленного в системе [.NET 8.0 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/sdk-8.0.426-windows-x64-installer). Зачастую этот компонент уже установлен на вашем ПК.
2. **Self-contained сборка:** Автономный вариант, в который **уже полностью вшит .NET 8 Runtime**. Весит больше, зато гарантированно запустится на любом компьютере без необходимости доустанавливать сторонние фреймворки.

## 🧠 Как это работает?

ZapretGate — это визуальная обёртка (GUI) для утилиты [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Вот что происходит под капотом:

1. **Менеджер процессов (`winws.exe`)**  
   Когда вы нажимаете центральный замок, приложение запускает выбранный профиль стратегии (`.bat` / аргументы `winws`) от имени администратора. Все запущенные процессы отслеживаются в реальном времени — можно сразу видеть, работает обход или нет.

2. **Сохранение настроек**  
   Все пользовательские параметры (выбранный путь к каталогу zapret, активная тема оформления, настройки автозапуска и последняя выбранная стратегия) автоматически сохраняются в системный файл конфигурации:  
   `%AppData%/Roaming/ZapretGate/settings.json`.

3. **Значок стратегии скрывается**  
   Процесс `winws.exe` не показывается в панели задач — его значок **намеренно скрыт**, чтобы не захламлять панель задач.

4. **Автопоиск стратегий**  
   При первом запуске программа попросит указать корневую папку zapret. Она сама просканирует каталог, найдёт все доступные конфигурации обхода, подсветит рекомендуемые и покажет их в удобном выпадающем списке.

5. **Защита и бэкапы списков (`lists/`)**
   * При переключении режимов IPSet (`loaded`, `any`, `none`) приложение автоматически создаёт или восстанавливает резервные копии (`ipset-all.txt.backup`), оберегая ваши настройки от потери.
   * При обновлении репозитория с GitHub файлы пользовательских настроек (`list-general-user.txt`, `list-exclude-user.txt`, `ipset-exclude-user.txt`, `game_filter.ports`) **никогда не затираются** и сохраняются в неизменном виде.

6. **Обновление репозитория**  
   Прямо из вкладки «Настройки» можно скачать свежую версию `zapret-discord-youtube` с GitHub. Приложение **само завершит активные процессы `winws`**, чтобы файлы не были заняты системой, распакует архив и аккуратно обновит компоненты.

7. **Тестирование и проверка DPI**  
   Встроенный сервис автоматически запускает PowerShell-скрипт `test zapret.ps1` из папки `utils`, перебирает стандартные конфиги, парсит вывод в реальном времени и показывает, какая стратегия лучше работает именно у вас. Есть отдельный режим **DPI Checker** для проверки фильтрации у провайдера.

## 🛠️ Основной функционал

### Главная панель и управление обходом
- **Кнопка-замок** — включение и отключение обхода одним кликом.
- **Статус подключения и живой таймер работы** — сразу видно, сколько времени обход активен.
- **Выбор стратегии** — выпадающий список всех найденных конфигураций из папки zapret.

### Тестирование и диагностика DPI
- **Автоподбор стратегии** — запуск скрипта `utils/test zapret.ps1` через PowerShell с парсингом вывода в реальном времени.
- **Режим DPI Checker** — отдельный сценарий проверки, как именно провайдер фильтрует трафик.
- **Прогресс-бар с текущим шагом** (`[N/M] имя_стратегии`) и автоматическая остановка при отмене.
- **Авто-завершение старых процессов `winws`** перед началом теста, чтобы результаты были чистыми.

### Игровой фильтр (Game Filter)
Четыре режима работы, которые хранятся в `utils/game_filter.enabled`:
- `disabled` — фильтр выключен (файл удаляется).
- `all` — обрабатывать все игровые порты.
- `tcp` — только TCP.
- `udp` — только UDP.
- `custom` — собственный диапазон портов (настраивается во вкладке «Сервис», по умолчанию `1024-65535`).

### IPSet-фильтр
Три режима работы со списком `lists/ipset-all.txt`:
- `loaded` — использовать текущий список IP-адресов.
- `none` — заглушка (`203.0.113.113/32`), список фактически отключён.
- `any` — пустой файл, обрабатываются все адреса.

### Подмена Active Fakes
- Управление файлами `ACTIVE_DISCORD_UDP.bin` и `ACTIVE_GAME_UDP.bin` в папке `bin`.
- Автоматическое **сопоставление по SHA-256** с исходными `.bin`-файлами: приложение понимает, какой именно фейк сейчас активен, а какой — «пользовательский».
- Список всех доступных фейков подтягивается автоматически.

### Автообновление репозитория zapret
- Скачивание свежей версии напрямую с GitHub (`main.zip`) и распаковка во временную папку.
- **Превентивное завершение `winws.exe`** до начала копирования файлов — чтобы не было блокировок DLL и бинарников.
- **Рекурсивное копирование** с защитой пользовательских файлов (`*-user.txt` и `game_filter.ports`).
- Отображение текущей версии из `.service/version.txt`.

### Диагностика системы
Встроенная проверка «здоровья» окружения:
- **Служба фильтрации Windows (BFE)** — должна быть активна, иначе `WinDivert` не заработает.
- **Конфликтующие процессы**: `AdguardSvc`, `GoodbyeDPI` — если найдены, приложение предупредит.
- **Драйвер WinDivert64.sys** — проверяется наличие файла в папке `bin/`.

### Обслуживание Discord
- **Обновление `hosts`** — загрузка актуальных записей с GitHub и добавление их в системный файл (для корректной работы голосовых шлюзов Discord).
- **Очистка кэша Discord** — завершает `Discord`/`DiscordPTB` и удаляет папки `Cache`, `Code Cache`, `GPUCache` из `AppData`.
- **Обновление IPSet-списка** — ручная загрузка актуального `ipset-all.txt` с GitHub.
- **Редактирование пользовательских списков** — открытие `*-user.txt` в блокноте прямо из приложения.

### Системная интеграция
- **Автозапуск и «Ультра-автозапуск»** — запуск вместе с Windows и мгновенная активация выбранной стратегии.
- **Гибкие темы оформления** — в окне настроек вы можете с ними ознакомиться и применить.

## 🚀 Установка и использование

1. Скачайте последнюю сборку установщика (`setup.exe`) со [страницы релизов](https://github.com/AlaskaGLHF/ZapretGate/releases/latest).
2. Запустите скачанный установщик и выберите удобную папку для установки (рекомендуется избегать кириллицы и пробелов в пути, например: `C:\ZapretGate`). Установщик автоматически создаст все необходимые ярлыки.
3. Запустите **`ZapretGate.exe`** (программа запросит права администратора, которые необходимы для работы сетевого драйвера `WinDivert`).
4. **Мастер первого запуска:**
   * При первом старте откроется окно приветствия. Нажмите кнопку **«Выбрать папку с Zapret...»** и укажите корневой каталог с утилитой `zapret-discord-youtube` (если её ещё нет, предварительно скачайте репозиторий [Flowseal](https://github.com/Flowseal/zapret-discord-youtube)).
   * Программа мгновенно проверит выбранную директорию. Как только папка будет распознана, появится зелёный статус с количеством найденных стратегий, после чего станет активна кнопка **«Продолжить»**.
   * На втором шаге **настоятельно рекомендуется ознакомиться с README.md**, а также можно прямо в этом окне запустить автоматический тест для подбора лучшей стратегии под вашего провайдера.
   * Нажмите кнопку **«Перейти в приложение»**.
5. Если вы не запускали тест на первом экране, вы всегда можете открыть вкладку **Сервис → Тестирование**, чтобы проверить конфигурации и найти оптимальный вариант (после теста лучшая стратегия автоматически пометится в выпадающем списке как «Лучшая»).
6. На главном экране выберите нужную стратегию из списка и нажмите центральную кнопку-замок. Готово — обход запущен!

## ❓ Частые вопросы и решение проблем

### Антивирус удаляет файлы / ругается на WinDivert
> **Это нормально.** Утилита `WinDivert` перехватывает сетевые пакеты — без этого обход не сработает. Некоторые антивирусы (и встроенный Защитник Windows) могут на это реагировать ложными срабатываниями (детект `RiskTool.Multi.WinDivert` или `PUA`). Просто добавьте папку с приложением в исключения антивируса.

### Я запустил обход, но не вижу значок на панели задач — это ошибка?
> **Нет, это так и задумано.** Значок процесса `winws.exe` намеренно скрывается с панели задач, чтобы не захламлять панель задач. Управлять обходом всё равно нужно через окно ZapretGate — там же отображается актуальный статус и таймер работы.

### Кнопка «Обновить Zapret» выдаёт ошибку подключения к сети
> Проверьте интернет и доступ к GitHub, либо временно отключите VPN / Proxy / DNS — это может вызывать ошибку при скачивании репозитория.

### Обход перестал работать
> Стратегии со временем устаревают: провайдеры меняют фильтры. Попробуйте выбрать другую стратегию в списке на главной или обновите репозиторий через настройки. Также можно прогнать тест заново.

### Приложение не запускается / вылетает
> Проверьте три вещи:
> 1. У вас **Windows 10 или 11** и **архитектура x64**.
> 2. Путь к папке не содержит кириллицу и пробелы.
> 3. Приложение запускается **от имени администратора** — это обязательно для работы `WinDivert`.
